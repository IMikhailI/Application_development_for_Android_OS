## Содержание

- **lab1/** — геометрическая проверка четырёхугольника и определение типа параллелограмма.
- **lab2/** — поиск минимума функции на интервале с проверкой шага.
- **lab3/** — обработка списка чисел и сравнение способов изменения коллекции.
- **lab4/** — модель шахматных фигур и поиск фигур, атакующих заданную клетку.
- **lab5/** — проект Android Studio с Activity на Kotlin.
- **lab6/** — отдельные задания по тексту, кнопкам и калькулятору.

Работы расположены в отдельных каталогах; единой сборки для всего репозитория нет.

## Запуск Android-проекта

Откройте **lab5/** в Android Studio и соберите приложение через Gradle. Остальные лабораторные файлы Kotlin можно открыть в IDE с поддержкой Kotlin; инструкции запуска зависят от задания.

## Структура

В **lab1/**–**lab4/** находятся исходники **Main.kt**. Android Studio проект и его ресурсы находятся в каталогах лабораторных работ с Gradle-конфигурацией.
